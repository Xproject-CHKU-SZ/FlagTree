# F08 当前执行方向（2026-09-29 确认；2026-10-22 更新选卡授权）

项目核心是 **FlagTree 编译层与真实模型适配优化**。F08 的图级生命周期、别名和缓冲规划必须最终服务于 FlagTree 编译执行链，而不是形成独立的 ATen 调优项目。

当前优先级：真实模型图 → 既有 G1/G03 合法性分析 → 显式图级 lowering/缓冲绑定 → FlagTree PPU 编译与执行证据 → 多模型受控 A/B。模型级缓冲规划可在图/运行时层实现；不能把它写成已新增 MLIR Pass 或已完整接入生产模型服务。

- 保留 PyTorch 为数值与性能对照，不再优先扩展纯 ATen 原型调优。
- 三臂：PyTorch 原算子、FlagTree 独立输出、**同一 FlagTree 编译 kernel** 同址输出。后两臂用于隔离缓冲优化收益。
- 编译门禁：真实 TTIR、TTGIR、LLVM IR、PPU hgbin、实际加载与同步执行证据。导入成功/安装版本/环境变量不足以通过。
- 默认关闭，只读使用共享模型。先 MiniLM，再 BGE-small/base/large；每模型重新导出、验证，未知语义拒绝，不套用六 GELU/固定三模块假设。
- 数值阈值必须显式指定并留档；同一编译 kernel 的独立输出与同址输出必须逐位一致。失败不偷偷放宽阈值、不 copy 冒充复用、不降级为 ATen 后仍声称 FlagTree。
- 总峰值 allocated/reserved 与延迟分别报告；预热前分配不等于节省显存，短程测量不等于长稳/完整 F08 验收。
- 历史源快照、基线、负结果、失败记录、冻结交付包保留；清理仅针对确定无用途的临时产物，优先可恢复。
- 本地源码修改后给出精确上传清单和校验命令；暂停自动日报。
- 2026-10-22 用户明确更新常规选卡授权：后续设备任务在团队允许使用的资源范围内，自动选择当时未被使用的 PPU，不再固定物理卡 14，也不逐卡重复请求用户确认；已知预约/保留/禁用卡仍排除。具体检查与复现实验边界见同目录 `F08-PPU自动选卡规则_20261022.md`。
- 自动选卡不等于跳过检查：启动前核查完整进程表、利用率、已认可空载显存基线；导入设备运行时前固定本次物理卡并显式传给子进程，再验证 PID→物理卡和逻辑设备映射。同一 gate/A-B/长稳任务组内固定卡号，不混卡拼表；无安全空闲卡则等待或停止，不终止他人任务。
- 现有冻结脚本仍可能写死卡 14。新策略必须在新的非冻结入口中完成参数化与回归后才用于其他卡，不得绕过旧护栏；历史证据中的卡 14 不改写。当前 CPU-only 任务不因选卡授权改变而自动开始设备实验。
