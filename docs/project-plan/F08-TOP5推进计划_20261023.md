## 实施与门禁

先小规模真实模型门禁，通过后立即按同输入、同设备、同kernel做三臂，不再单独停在审计环节。

BGE诊断不在计时路径，不保留tensor、不clone，使用原释放规则；同步诊断可能改变分配重叠，
所以与正常性能结果分开解释，未能归属的kernel暂态/工作区如实保留。

Qwen明确FP32、单次Embedding关闭无用生成cache，两条路径使用相同设置。
仅对真实图中合法的SiLU→等形状Mul接入FlagTree，不改SiLU数学实现；选定输入buffer须经全部alias
与最后消费者证明。检查独立输出/同址输出两种绑定、非目标操作数不变、边界长度及全图逐位一致。

若导出、多输出绑定、数值或设备门禁失败，保留具体现场，不放宽、不换原生成功表述，
先报告可定位阻塞；已经完成的BGE阶段不回滚、不补造Qwen性能。
