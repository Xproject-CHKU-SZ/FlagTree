## 功能与入口

| 范围 | 源码 | 边界 |
|---|---|---|
| G01模型生命周期 | `python/flagtree/memory_planner/{schema,liveness}.py` | storage别名联合生命周期、峰值来源、控制流保守诊断，不是设备收益 |
| G02主规划器 | `python/flagtree/memory_planner/offset_planner.py` | 候选顺序、偏移/对齐、安全验证，离线报告不自动授权运行时 |
| G02早期离线接口 | `python/flagtree/memory_planner/reuse.py` | 保留兼容/历史能力，不作为真实运行时主实现 |
| G03合法性 | `python/flagtree/memory_planner/inplace_legality.py` | 全storage别名、最后消费者、身份化绑定、设备/stream与推理边界 |
| FlagTree GELU桥接 | `python/scripts/f08_flagtree_eval/{kernel,graph,worker}.py` | 实际PPU编译/启动；worker中的build/compile辅助函数被新入口复用 |
| G02真实arena机制 | `python/scripts/f08_flagtree_g2_runtime_20261022/` | offset=0同形状GELU输出，保守统一屏障；历史总峰值增加，不宣称收益 |
| 五模型三臂/长稳驱动 | `python/scripts/f08_flagtree_model_compare_20261022/` | 同kernel out/inplace隔离复用收益，torch是额外参考 |
| 长稳报告 | `python/scripts/f08_flagtree_longrun_report_20261022/` | 只读有限检查点；无增长不等于证明无泄漏/越界 |
| G02历史接入审计 | `python/scripts/f08_flagtree_g2/` | CPU/历史证据读取，设备机制入口不是该目录 |
| Qwen当前候选 | `python/scripts/f08_flagtree_top5_20261023_v3/` | max.dim values/indices显式G1绑定，真实FlagTree Mul门禁尚待服务器 |

Qwen v1/v2源目录作为失败现场对应版本保留：v1卡BatchedTensor，v2规范化在PPU通过后卡max.dim。
v3不改pooling、mask、执行顺序或乘法kernel，不把tuple视为一个storage；
通过G1/G03与完整模型0/0后才执行三臂，不是全模型FlagTree、完整SwiGLU融合或新MLIR Pass。
当前主线仍为BGE-M3与Qwen；MiniLM只作轻量回归，不扩大相似模型凑覆盖。

## 本地软件验证（无PPU）

```bash
python3 -B -m unittest discover -s python/test/unit/memory_planner -p 'test_*.py'
python3 -B -m unittest discover -s python/scripts/f08_flagtree_top5_20261023_v3 -p 'test_*.py'
```

本地无torch，因此实际torch执行测试会跳过；CPU合同通过不等于设备/模型成功。
