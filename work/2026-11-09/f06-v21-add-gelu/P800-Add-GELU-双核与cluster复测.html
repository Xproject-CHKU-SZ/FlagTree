运行条件

默认入口实测卡为 5, 7，开启双核搜索的实测卡为 5, 7。每项的各候选和 eager 做同卡配对。主轮在五次采样中均为 0 MiB、0% 的卡上启动，补测使用低负载卡。运行期间有其他作业，接近 1× 的差异不作为稳定胜出。

个别进程在输入传输、Inductor 编译或设备同步时超时，已用同镜像补测。逐项取首个成功测量，退出失败的尝试保留在原始记录中。
