P800 Add + LayerNorm · 官方库数值对照

在高均值、低行内方差的输入上，厂商 eager LayerNorm 的倒标准差与稳定计算存在明显偏差。Add 的输出逐元素对照通过；本地 F06 融合核喂原始两路输入或已完成 Add 的矩阵加零，测试输出均数值相等。

官方源码和实际运行库

检查了 Documents/FlagTree-official 的干净 main 检出 6b1549dd。其官方 LayerNorm 教程先计算行均值，再累加与均值之差的平方。F06 cluster 核则先减行首元素，再对平移后的值求二阶矩。F06 子系统由本地添加。P800 个人容器中的官方二进制构建自 d65b6d70；两个提交间只有四个 CI 文件改动，XPU 和 Triton Python 子树完全相同。

在物理卡 6 上，用官方及 v25 两套编译器分别运行官方原版前向函数和同一份本地 F06 源码。覆盖 FP32、FP16，有/无 affine，64×1024、512×1024、2048×2048，以及普通与高偏置输入；512×1024 另测偏置 0 和 100。两栈的 64 对输入、结果字节和实际执行核机器码哈希全部逐项核对相同。官方教程接受已物化的 Add 输出，F06 控制使用固定 R=4、C=512；此前的正式 F06 校准记录可单独核对。
