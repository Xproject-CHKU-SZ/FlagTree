哪些差异会导致输出不同

Mul+Sum 的乘法输出在单个 +Inf 输入上仍为 +Inf。P800 eager 在同一份 FP32 乘积上分情况调用不同的实际设备核。将 2048×2048 输入批量归约，reduce_mt 给出 NaN；单取该行，reduce_1d 给出 +Inf。

当 y 为无穷而 old_sum 有限，d−y 会计算 Inf−Inf，NaN 随补偿项进入后续累加。2048×2048 和 512×1024 分别由上表中两个不同的写回位置主导。200 个设备输出对照包含 ±Inf、NaN、有限对照、不同位置及相同字节的副本。消融只用于个人容器的独立诊断进程。

对应机器码。eager cluster 011cfe48da → cluster 9e3bdbd180。融合 SDNN 候选 sdnn f04f1eb077。

LayerNorm 的 FP32 eager 方差计算在 0x1604–0x160c 等代码段依次求均值平方、与二阶矩相减、加 eps。cluster 的 flat_reduce 使用平移后的值求矩。三种尺寸上均测试了普通和高偏置输入。eager cluster 2b77be6df1 → cluster bb257ff989。cluster cluster d97e208535。

Add+SiLU 的 512×1024 FP32 用例只在广播偏置首元素放入 +Inf，SDNN 候选有 512 个元素与 eager 不同。第一个差异的候选输出为 nan，设备 eager 为 inf。同一份加法结果送 CPU FP64 SiLU 可独立核对。
