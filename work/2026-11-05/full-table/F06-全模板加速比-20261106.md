# F06 全模板 × 矩阵形状 加速比（2026-11-06 实测）

## 环境与方法

- 主机：p800-152，物理卡 2（`F06_PHYSICAL_DEVICE=2`），单卡；
- 环境：FlagTree 0.7.1a1+xpu3.6 wheel + 11-05 overlay（`graph_fusion`）；
- 计时：warmup 5 次 + 计时 20–30 次取平均；
- 两个基线：**eager**（torch 原生算子组合）与 **Inductor**（同环境 F06 图编译）；
- 比值 = 基线耗时 ÷ 我们耗时（>1 = 我们更快）；
- `*` = 我们的结果超容差（invalid，实际回退 eager）；`n/a` = 该轮小尺寸校验不可判；
- 共 156 用例（13 模板 × 6 形状 × 2 精度），其中 matmul 60 例因 152 XBLAS 故障无法测量。

## 逐模板结论

| 模板 | 结论 | vs eager | vs Inductor |
|---|---|---|---|
| Mul + Sum（大尺寸） | ✅ 领先 | **1.09–1.10×** | 5.0–5.1× |
| Mul + Sum（中尺寸） | 略慢 | 0.94–0.98× | 1.5–2.2× |
| Mul + Sum FP16 大尺寸 | ❌ 大幅落后（无 f16 dsa 路径） | 0.15–0.48× | 1.0× |
| Mul + Sum keepdim | 同上 | 0.94–1.10× | 1.4–5.0× |
| Add + SiLU | ✅ 中尺寸领先 | **1.10–1.18×** | **1.3–1.8×** |
| Add + GELU（exact） | ✅ 大尺寸领先 | **1.40–1.49×** | 1.2× |
| Add + GELU（tanh） | ✅ 大尺寸领先 | **1.17–1.72×** | 1.0–1.2× |
| Add + LayerNorm（无仿射） | ✅ 小中尺寸领先 | **1.15–1.22×** | 1.4–11.3× |
| Add + LayerNorm（仿射） | ❌ invalid（框架传不了参） | ≈1.0×（eager） | 1.0× |
| Add + Softmax | ❌ 全部 ≤0.92×，大尺寸回退 | 0.09× | 1.0–4.5× |
| MatMul 系列 5 个 | ⏸ 无法测量 | — | — |

## 一句话总结

Mul+Sum/keepdim（大尺寸）、Add+SiLU（中尺寸）、Add+GELU（大尺寸）、Add+LayerNorm（小中尺寸）
已超过 eager；Softmax、大尺寸 LayerNorm、FP16 大尺寸 Mul+Sum、仿射 LayerNorm 仍回退；
MatMul 系列等空闲卡或新主机部署后补测。
