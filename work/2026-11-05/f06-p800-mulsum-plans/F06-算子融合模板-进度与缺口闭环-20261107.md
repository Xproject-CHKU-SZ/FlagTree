## 1. 已完成/已具备的证据（按缺口）

| 表内判据 | 证据 |

### F06-G02 合法性与数值约束（P0）

| 约束 | 实现 |
|---|---|
| 别名/副作用 | matcher 只做结构匹配、不在规划期执行模型；`out=` 参数、非 1.0 alpha、非最后一维 softmax 直接拒绝 |
| dtype/广播 | `a.dtype == b.dtype` 检查；1D bias 广播仅允许 `(n,)`；形状 `m×n` 必须与输入一致 |
| 精度/数值 | fp32 SiLU LUT 余量 +2.38e-3 > 3e-4 → 拒绝 LUT 改 cluster 精确 exp；fp16 走 SDNN LUT；LUT 窗口 ±8 越界即拒绝 |
| 资源 | LM 预算（TLE 8KB/core）、VRF 累加器规模；`OutOfResources` 不再掩盖真实错误 |
| 拒绝单测 | `F06子模块测试报告-20261107.md`：G01–G05  legality **19/19** 通过 |
| 回退 | `_decline_*`（mulsum/softmax/layernorm）按 kind×m×n×dtype 决策；softmax 全回退、LN ≥1M 元素回退、mul_sum f32 只留 2048² 类 |

### F06-G03 核心融合组合（P0）

表内要求：MatMul+Bias、MatMul+Bias+Activation、Norm/Softmax/Reduce 组合。
已完成 **12 个模板 × 3 尺寸 × 2 dtype = 72 用例**（`F06完整加速比总表-20261107.md`）：

| 组合 | 路由 | 最佳 vs eager |
|---|---|---|
| MatMul+Bias | native_mm（SDNN dot+epilogue） | 1.05–1.48× |
| MatMul+Bias+ReLU | native_mm 单 kernel epilogue | 1.48–1.91× |
| MatMul+Bias+GELU(exact) | SDNN LUT 单 kernel | 1.22–3.12× |
| MatMul+Bias+GELU(tanh) | Inductor | 1.15–1.80× |
| MatMul+Bias+SiLU | fp16 SDNN LUT；fp32 cluster 精确 exp | 1.13–1.17× |
| Add+SiLU | cluster 融合 | 1.06–1.16× |
| Add+GELU(exact) | cluster 融合（erf） | 1.44–1.56× |
| Add+GELU(tanh) | Inductor | 1.15–1.80× |
| Add+LayerNorm(+affine) | cluster 融合 | 1.13–1.21× |
| Add+Softmax | 回退（TLE 0.44–0.72×） | 1.00× |
| Mul+Sum / keepdim | cluster 融合 | 1.10× |

### F06-G04 动态 Shape 融合（P0）——**未完成**

- 现状：所有 kernel 的 `N/R/C` 都是 constexpr，matcher 用具体 `m,n` 匹配；缓存键含 shape；
- 缺：符号 Shape 传播、资源限制进入匹配、失败安全回退的统一入口；
- 已有基础：`_inference.py`（静态推断）、`_resource_*`（资源计划/基准）、回退开关；
- 判定：**进度 0.2**，是 F06 当前最大缺口（对应表内 7 周）。

### F06-G05 跨芯片收益治理（P1）——部分完成

- 现状：P800 单芯片已有逐用例 A/B（eager/Inductor/our）、精度校验、负收益自动回退（`_decline_*` + 子模块测试 19/19）；
- 缺：通用精度/性能/编译时门禁、芯片差异化白/黑名单、跨芯片 A/B；
- 判定：**进度 0.5**（8 周 → 剩余约 3 周）。
