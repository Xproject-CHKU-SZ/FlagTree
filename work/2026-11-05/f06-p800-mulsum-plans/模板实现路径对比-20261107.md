# 全部模板实现路径对比：本地融合 vs FlagGems vs eager

口径：P800（arch 3），`our` 为回退策略生效后的实际路由；数据取自
`F06完整加速比总表-20261107.md`（72 用例）与本次 FlagGems/TLE 实测。

## 1. 总览

| 模板 | 我们的路径（实测 vs eager） | FlagGems 的路径 | eager 的路径 |
|---|---|---|---|
| mul_sum | cluster 2D tile 融合（f32 2048² 1.10×；其余回退 1.00×） | `mul` pointwise + `sum` TLE row-reduce（**两个 kernel，不融合**） | ATen mul + sum → 两个 vendor kernel |
| mul_sum_keepdim | 同上（1.10×） | 同上 | 同上 |
| add_silu | cluster 融合 kernel（1.06–1.16×；f32 2048² 回退） | `add` + `silu` pointwise（两 kernel；`silu = x/(1+exp(-x))`） | ATen add + silu → 两个 vendor kernel |
| add_gelu_tanh | 回退/Inductor（1.15–1.80× 靠 Inductor 赢；小尺寸回退 1.00×） | `add` + `gelu(tanh)` pointwise（tanh 公式手写） | ATen add + gelu → 两个 vendor kernel |
| add_gelu_exact | cluster 融合（erf 标量 libdevice，1.44–1.56×） | `add` + `gelu(erf)` pointwise（`tl_extra_shim.erf`） | ATen add + gelu → 两个 vendor kernel |
| add_layernorm | cluster 融合小尺寸（1.13–1.21×）；≥1M 元素回退（TLE 版 0.57–0.69× 仍低于 eager） | `add` + `layernorm`（pointer/TLE；实测 0.04–0.12× eager） | ATen add + layer_norm → 两个 vendor kernel |
| add_softmax | 全部回退（TLE 版 0.44–0.72×） | `add` + `softmax`（TLE fused / pointer multirow；0.32–0.39× eager） | ATen add + softmax → 两个 vendor kernel |
| matmul_bias | native_mm（SDNN dot + epilogue，1.05–1.44×） | `matmuladd` 自定义 GEMM（tile/warps 规则，bias 物化 2D） | ATen addmm → vendor XBLAS/XDNN GEMM |
| matmul_bias_relu | native_mm 单 kernel epilogue（1.78–1.91×） | `matmuladd` + ReLU（小形状融合，大形状独立 pointwise） | addmm + relu（2 kernel） |
| matmul_bias_gelu_exact | sdnn LUT 单 kernel（1.22–3.12×） | matmuladd + gelu（2 kernel） | addmm + gelu（2 kernel） |
| matmul_bias_gelu_tanh | 回退/Inductor（1.15–1.80×） | matmuladd + gelu(tanh)（2 kernel） | addmm + gelu（2 kernel） |
| matmul_bias_silu | fp32 大尺寸回退、512×1024 native_mm(cluster) 1.14×；fp16 sdnn LUT 1.13–1.15× | matmuladd + silu（2 kernel） | addmm + silu（2 kernel） |

## 2. 分类对比

### 2.1 纯逐元素（add / mul / silu / gelu）

| 维度 | 本地 | FlagGems | eager |
|---|---|---|---|
| kernel 数 | **1（融合 add+act）** | 2（add、act 各一） | 2 |
| 生成方式 | 手写 Triton（flat 模块，XBLOCK/BLOCK 固定 tile） | `pointwise_dynamic` 代码生成（1D tile，buffer 4096，unroll 8，warp 启发式） | vendor C++ 预编译 |
| 数学 | cluster：`tl.exp`/`tl.erf`（erf 走标量 libdevice）；fp16 SiLU 走 SDNN LUT | `tl.exp`/`tl.fdiv`/`tl_extra_shim.erf/tanh` | 向量库函数（primitive_exp/erf） |

结论：我们靠**融合**赢了 1.06–1.56×；FlagGems 不融合，单 op 与 eager 持平或略慢
（他们也没有 add+act 的融合实现，只有 mul-gated 的 `silu_and_mul`/`gelu_and_mul`）。

### 2.2 归约类（mul_sum / softmax / layernorm）

| 维度 | 本地 | FlagGems | eager |
|---|---|---|---|
| mul_sum | cluster 2D tile + 分块累加（f32 2048² 1.10×） | `mul` + `sum`：pointer 路径实测 **0.01–0.45×**，TLE row-reduce **0.8–1.05×**（XBLOCK 512、LM 4KB/core、flat [n/4096,4096]） | vendor reduce，单 kernel |
| softmax | pointer multirow（0.26–0.88×）、TLE 版（最高 0.53–0.72×） | TLE fused（长行）/ pointer multirow（中行）→ 0.32–0.39× | 单趟 online + 向量 exp（33–53 µs） |
| layernorm | cluster 双累加器（0.15–0.23× 大尺寸）；TLE 单 chunk（0.57–0.69×） | pointer/TLE（实测 0.04–0.12×） | 单趟 + 向量数学（18–52 µs） |

结论：归约类是三家中**差距最大**的一类。FlagGems 自己也承认 pointer 归约只有
0.01–0.45×、必须走 TLE 才能到 0.8–1.05×；我们在 mul_sum 上已经进了这条线
（1.10×），但 softmax/layernorm 仍落后。

### 2.3 矩阵乘类

| 维度 | 本地 | FlagGems | eager |
|---|---|---|---|
| 主体 | SDNN `tl.dot`（native_mm），tile `{512:(256,256,64,8)}` / 默认 `(64,512,64,8)` | `matmuladd` 自定义 GEMM：BM=128/256、BN=128/256/512、BK=128/256、fp32 wide-N warps=16 | vendor XBLAS/XDNN GEMM（addmm） |
| bias | epilogue 融合（1 读） | bias 先物化 2D 再 epilogue | addmm 融合 |
| 激活 | fp16→SDNN LUT 单 kernel；fp32 大形状拒绝 LUT，走独立 pointwise（cluster 向量 exp） | 小形状/bf16 融合 epilogue；大 fp16/fp32 **拆分独立 pointwise** | 单独 kernel（addmm 后再 act） |
| 实测 | matmul_bias 1.05–1.44×、relu 1.78–1.91×、gelu_exact 1.22–3.12× | 未在本环境跑通（`matmul_bias_activation` 触发 LLVM 断言崩溃） | 1.00（基线） |

结论：MatMul+Bias/ReLU 我们已超 eager；GELU(exact) 靠 LUT 大幅领先；GELU(tanh)/SiLU
受限于"无 tanh intrinsic / fp32 LUT 窗口"，分别走 Inductor 和回退。

## 3. 差距归因（三家对比视角）

1. **融合层数**：我们是"一个模板一个融合 kernel"；FlagGems 基本按单 op 实现（只有
   matmuladd、silu_and_mul 等少数融合）；eager 的融合由 vendor 库决定（addmm 融合 bias）。
   → 逐元素类我们靠融合赢，归约类靠融合不足以弥补归约 lowering 差距。
2. **归约 lowering**：eager 用 C++ 向量归约；FlagGems 明确记录 pointer 归约 0.01–0.45×、
   TLE 才 0.8–1.05×；我们的 pointer 归约同样慢，TLE 后才接近。
3. **向量数学**：eager 有 `primitive_exp`/SIMD 512-bit；FlagGems 只有 `tl.exp`
   （逐 lane）；我们有 SDNN LUT（窗口 ±8）和 cluster `tl.exp`，但没有全范围向量 exp。
4. **数据搬运**：eager 用 LM batch + DMA；FlagGems 用 `tle.gpu.copy` 描述符 DMA；
   我们的 flat/reduce 仍是指针寻址（TLE 只在新 softmax/LN 里启用）。
