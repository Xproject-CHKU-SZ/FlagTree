最新的 78 项正式路由和 B2 余差定位见 [P800 v7 分组指数降层复测](../../2026-11-09/f06-grouped-exp/F06分组指数修复与余差定位.html)。[v6 双路径复测](../../2026-11-08/f06-gap-fix/F06双路径实测与耗时定位.html) 提供修复前对照。[v4 正式入口复测](../../2026-11-08/f06-repair/F06修复后实际路由与加速比.html) 保留上轮数据。下表保留原候选测试。当时的 eager 回退按 1.00× 计，未包含外层 torch.compile 调用开销。

harness `eager_table.py`，warmup + 多轮取最小，CUDA events；精度门禁 fp32 atol/rtol 3e-4、

## 4. 各模板瓶颈与结论

| 模板 | 当前瓶颈 | 结论 |
|---|---|---|
| mul_sum / keepdim | 访存地板（31.8 µs ≈ 2 读 + 小输出） | 已贴地板；fp16 大尺寸 kernel 退化但回退保护 |
| add_silu | 访存+数学串行（78.3 = 32.8+43，eager 72.5 有 overlap） | 2048² 回退；需官方流水/向量 exp |
| add_gelu_tanh | 已贴 sigmoid 数学地板 77.9（实测 81.5） | 2.50×（fp32）/2.54×（fp16），无本地空间 |
| add_gelu_exact | erf 标量地板 168.9（实测 172.4） | 1.47×；官方向量 verf 可到 ~2× |
| add_layernorm / affine | 小尺寸 launch 地板；大尺寸 reduce/编译错误 | 1.13–1.23×；大尺寸回退 |
| add_softmax | reduce lowering + 无向量 exp | 全回退；TLE 内核仍慢于 eager |
| matmul_bias | fp32 算力峰值（36.3） | 1.06–1.31×；fp16 2048² 回退 |
| matmul_bias_relu | 算力峰值 + 免费 epilogue | 1.44–1.80× |
| matmul_bias_silu | 融合 epilogue（36.3 + ~6 µs） | **1.85–2.08×（fp32）**、1.12–1.16×（fp16） |
| matmul_bias_gelu_tanh | matmul 36.3 + gelu_tanh 77 ≈ 113 | **2.20×**（fp32）；fp16 回退 |
| matmul_bias_gelu_exact | matmul 36.3 + LUT 54 = 90.4 | **3.12×**，全尺寸最优 |

## 5. 数据来源

- 二进制类（add_*/mul_sum/LN）：`cluster,eager` 路由，卡 4；
- matmul 基础/relu/silu：`native_mm,cluster,eager`，卡 5；
- matmul+GELU：`native_mm,sdnn,eager`，卡 4/6（sdnn LUT 路径精度 `valid=true`）。
- 精度：全表 best 全部通过 fp32 3e-4 / fp16 3e-3；新增融合 SiLU 误差 1.97e-5
  （`精度回退检查-20261108.md`），GELU split 误差 4.77e-7。
