## 后续保存约定

1. 每个已完成的周进度按 `work/YYYY-MM-DD/<项目>/` 保存，并更新上表；正在进行的开发继续在开发目录推进。
2. 每个版本包含源码、运行环境说明、测试入口、验证结果与 SHA-256 清单，注明哪些结果为历史数据、哪些为重新实测。
3. 已归档版本保留原貌。必要的修订另建明确标识的版本目录，并说明与原版本的差异。
4. 仅提交本次归档目录及索引，不混入工作区其他未提交改动。依赖大文件、编译缓存、凭据和远端连接配置不入库。

此约定用于后续归档，不会自动创建定时上传任务。
